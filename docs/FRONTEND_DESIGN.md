# B-SIDE 프론트엔드 디자인

2026-10-23. 기존 브랜드색 변경을 포함한 재디자인 요청에 따라 적용했다.

## 방향

설치된 `design-taste-frontend`의 앱 화면 절차를 사용했다. 선택한 방향은 **True-black flat**, seed **1339459303**이다. 미디어를 오래 감상하는 서비스이므로 장식보다 곡과 조작이 먼저 읽히는 구성을 선택했다. 방향을 다시 추첨하지 않았다.

컨셉: **B-SIDE의 함께 듣는 방을, 각자의 선곡이 이어지는 하나의 청취 공간으로 보여준다.** 실제 영상·썸네일, 곡명, 아티스트, 신청자와 다음 곡이 화면의 정체성을 만든다. 레코드의 중심과 홈에서 가져온 선으로 로고·파비콘을 맞췄다.

화면이 먼저 답하는 질문:

- 홈: 내 방과 참여한 방을 어디서 다시 열고, 새 방에는 어떻게 들어가는가?
- 방: 지금 무엇을 듣고 있고, 다음에는 무엇을 들을 것인가?
- 플레이리스트: 저장한 곡을 어떻게 찾아서 신청하는가?
- 설정: 방의 이름과 참여 방식을 어떻게 바꾸는가?

토큰은 `frontend/src/shared/index.css`, 공통 조작 스타일은 `frontend/src/shared/styles.ts`에 있다. 배경 그라디언트, 발광 효과, 블러 패널, 왕관 이모지, 장식용 조항 번호를 없앴다. 떠 있는 메뉴·대화상자의 그림자, 로딩 표시, 실제 시간 형식은 기능에 필요한 용도로 유지한다. 본문은 Inter와 한글 시스템 폰트 대체를 사용하며, 숫자는 tabular figures를 사용한다.

방 화면은 데스크톱에서 이름을 읽을 수 있는 200px 플레이리스트 영역, 유동적인 영상 영역, 대기열로 나눈다. 1024px 미만에서는 대기열을 서랍으로 열어 영상을 좁히지 않는다. 재생 중에도 곡 신청을 바로 열 수 있다. 제목·아티스트·신청자는 영상 아래 같은 왼쪽 선에 맞췄다. 재생·음량·투표 기능과 서버 상태 흐름을 유지했다.

컬렉션 패널은 상단 아이콘으로 접거나 펼친다. 접으면 72px 너비에 썸네일만, 펼치면 기본 200px 너비에 이름과 곡 수를 표시한다. 썸네일은 48px, 행 높이는 56px로 맞춰 이미지 사이 간격을 8px로 줄였다. 패널 오른쪽 경계를 드래그하면 184~420px 사이에서 너비를 조절하며, 더 좁게 끌면 접힌다. 영상 공간과 대기열에 필요한 너비를 남기도록 화면 크기에 따라 최대치를 제한한다. 접힘 상태와 펼친 너비를 브라우저에 저장한다. 경계에 키보드 포커스를 놓고 좌우 방향키로 조절하거나 Home으로 접고 End로 최대화할 수도 있다. 영상의 기존 중앙 정렬은 유지한다.

## 확인 결과

- `npm run build`, `npm run lint`, `npm test`: 통과, 테스트 51개 통과(컬렉션 너비·복원 검증 4개 포함).
- 홈과 방의 스킬 검사: 1440·768·390px 각각 **0 FAIL / 0 WARN**.
- 실제 Chrome에서 33개 화면 상태 확인: 로그인·비로그인 홈, 방, 대기열, 검색, 채팅, 설정, 초대, 플레이리스트, 빈 방, 참여 전 화면. 가로 페이지 넘침과 잡히지 않은 브라우저 오류 없음.
- 컬렉션 패널은 별도로 실제 마우스로 접기·펼치기·너비 조절, 새로고침 복원, 키보드 조절, 태블릿 제한, 모바일·비로그인 배치, 플레이리스트·채팅 열기를 확인했다. 접힘·펼침 상태에서 영상의 가로 중앙 오차는 0px였다.
- 홈은 소개 영역을 제거하고 방 목록을 본문으로 배치했다. 첫 줄 왼쪽에 방 코드 입력·참여, 오른쪽에 방 만들기를 배치하고 아래에 내 방·참여한 방 목록을 둔다. 보이는 페이지 제목과 코드 라벨을 없애고 입력칸에는 “방 코드” 플레이스홀더를 표시한다. 모바일에서는 참여 버튼을 화살표로 줄여 입력 폭을 확보한다.
- 소스 디자인 검사: FAIL 없음. 떠 있는 UI의 그림자, 시간의 0 채우기, 로딩 스켈레톤에 대한 정적 경고는 해당 용도로 유지했다.

브라우저 상태 확인에는 `.taste-skill/preview.mjs`의 localhost 전용 테스트 데이터를 사용했다. 실제 Discord 인증과 YouTube 스트리밍, 다중 기기 재생 동기화를 검증한 것은 아니다. 테스트 데이터와 촬영 결과는 Git에서 제외한 `frontend/.taste-skill/`에만 있으며 제품 코드에는 샘플 방·샘플 곡·샘플 계정이 추가되지 않았다. 추가한 폰트는 Google Fonts에서 불러온다. 장식 사진을 추가하거나 외부 사진을 제품 콘텐츠로 사용하지 않았다.

## 홈 재구성

기존 변경은 `codex/frontend-redesign` 브랜치의 `3f16bdb` 커밋으로 먼저 푸시했다. 이후 홈 화면에 한해 레이아웃을 다시 구성했다. 새 앱 방향표의 seed는 **1203627540**, 스타일은 **True-black flat**이며 기존 팔레트와 글꼴을 유지했다. 별도의 목적지가 없는 홈에 사이드바를 추가하지 않고 기존 브랜드·계정 헤더를 재사용했다.

첫 화면의 재료는 실제 방 제목, 현재 곡의 커버·곡명, 온라인 참여자와 대기 곡 수다. 곡명은 방 이름 아래에 배치하며 별도의 방 코드와 아티스트명은 표시하지 않는다. 슬로건과 소개 문단, 큰 참여 폼 카드를 제거했다. 방 목록은 전체 폭의 행으로 표현하고 로그인·빈 목록·로딩·오류 및 재시도 상태를 구분했다. 방 생성과 비로그인 코드 참여, 멤버십 나가기 동작을 유지했다. 한국어·일본어·영어를 함께 반영했다.

시각 검토 ROUND 1: 먼저 읽히는 것은 방 목록과 방 만들기다. 헤더·제목·코드 폼·목록·푸터는 같은 1120px 프레임 양끝에 맞췄다. 데이터가 많은 상태에서는 방 제목과 현재 곡을 두 열로, 모바일에서는 한 행 안의 두 줄로 표시한다. 가장 좁은 320px에서 코드 입력칸이 좁아지는 문제를 발견해 라벨을 위로 분리했다.

시각 검토 ROUND 2: 1440·768·390·320px의 로그인·비로그인 및 여러 방 상태를 확인했다. 긴 제목은 자기 열 안에서 생략되며 48px 썸네일과 나가기 버튼의 폭을 유지한다. 온라인 참여자 수는 `participants`의 `online` 값, 대기 곡 수는 `queue.length`를 사용한다. 목록을 채우는 테스트 데이터는 격리된 브라우저에서만 주입한다.

검사 예외: 방이 적을 때 목록 아래가 비는 경고는 실제 방 수를 그대로 보여주고 푸터를 화면 아래에 두기 때문에 유지한다. 방 코드의 고정폭 글꼴은 식별자를 읽고 입력하기 위한 용도다. 제품 코드에 샘플 방이나 장식용 통계를 추가하지 않았다.

홈 전용 브라우저 검증은 21개 화면·동작을 통과했다. 비로그인 방 생성 안내·Escape 닫기, 실제 코드 입력·Enter 참여, 로그인 방 생성 이동, 멤버십 나가기의 취소·실패·성공, 목록 로딩·오류·재시도 및 일본어·영어 표시를 확인했다. 화면 검사와 소스 검사의 FAIL은 0개이며, 가로 넘침·잡히지 않은 브라우저 오류는 없었다. 사용 중인 `127.0.0.1:5175`에서도 최신 홈 표시를 확인했다.

### 방 목록 통합 및 Figma 검토안 반영

상단에는 코드 입력과 참여만 두고, `+ 새 방`은 방 목록 제목 오른쪽으로 옮겼다. 비로그인 상태에서는 생성 버튼에 로그인 필요 여부를 표시하며, 본문 로그인 버튼은 작은 텍스트 링크로 바꿨다. 입력과 목록 사이 간격은 로그인 상태에 관계없이 40px이다. 코드 안내는 일반 자간으로 예시를 보여주며, 입력값은 대문자 6자로 제한한다. 참여 버튼은 6자 입력 전에는 비활성이고 입력 완료 시 밝은 배경으로 바뀐다. Windows 설치는 보조 텍스트 링크로 낮췄다. 프로필 옆 드롭다운 아이콘은 추가하지 않았다.

내 방과 참여한 방은 `방` 목록 하나로 합쳤다. 소유한 방을 먼저 표시하고 `호스트` 배지를 붙인다. 두 API 목록에 겹치는 방은 한 번만 표시하며, 소유하지 않은 참여 방의 나가기 기능은 유지한다. 배지는 방 소유 여부만 표시하며 재생 권한이나 멤버십 계약을 바꾸지 않는다.

통합 후 브라우저 검증은 1440·768·390·320px의 로그인·비로그인·다중 방, 빈 목록·로딩·오류·재시도, 방 생성·코드 참여·나가기, 일본어·영어 등 21개 상태·동작을 통과했다. 겹치는 방의 중복 제거, 호스트 배지와 나가기 버튼의 분리도 확인했다. 빌드·린트와 기존 테스트 51개가 통과했다.
